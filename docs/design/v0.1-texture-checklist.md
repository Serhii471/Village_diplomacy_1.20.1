# Village Diplomacy 0.1 — строгий каталог текстур

- Mod ID: `villagediplomacy`
- Формат: PNG
- Стиль: ванільний Minecraft pixel art
- Останнє оновлення: 20 жовтня 2026 року

## Як читати список

Кожен запис має формат:

```text
ID — розмір; точне пояснення вигляду
```

Фінальний файл у репозиторії утворюється так:

```text
ID: item/diplomatic_scroll
Файл: src/main/resources/assets/villagediplomacy/textures/item/diplomatic_scroll.png
```

Статуси:

- `[x]` — готово й додано до репозиторію;
- `[ ]` — потрібно підготувати;
- `[~]` — необов'язково для версії 0.1.

## 1. Готові текстури

### Предмети

- [x] `item/diplomatic_scroll` — 16×16; невеликий світлий пергамент, згорнутий або складений по діагоналі, з червоною стрічкою чи сургучевою печаткою; прозорий фон.
- [x] `item/leadership_seal` — 16×16; золота ручна печатка з червоною рукояткою або сургучним акцентом; силует має відрізнятися від золотого самородка; прозорий фон.
- [x] `item/trade_route_map` — 16×16; світла розгорнута карта з двома кольоровими позначками поселень і видимою лінією маршруту між ними; прозорий фон.

### Дипломатичний стіл

- [x] `block/diplomacy_table_top` — 16×16; верхня робоча поверхня столу з розгорнутою світлою картою або планом, кольоровими позначками та дерев'яною рамкою по краях.
- [x] `block/diplomacy_table_front` — 16×16; передня частина з темної теплої деревини, симетричні панелі або вертикальне декоративне розділення, чіткий контраст із верхньою картою.
- [x] `block/diplomacy_table_side` — 16×16; суцільна бічна дерев'яна панель того самого кольору, з помітною вертикальною текстурою дощок.

## 2. Обов'язкові текстури блоків

### Дорожній вказівник

- [ ] `block/route_signpost_board` — 16×16; світла або середньо-коричнева дошка з горизонтальним напрямком волокон, темними краями й чистою центральною ділянкою для програмного тексту.
- [ ] `block/route_signpost_post` — 16×16; вертикальний дерев'яний стовп із темнішою лівою або нижньою тінню, у тому самому стилі та палітрі, що й дошка.
- [ ] `block/route_signpost_arrow` — 16×16; контрастний наконечник стрілки з темного дерева або бронзи, який легко розпізнати з кількох блоків.

Назва поселення, напрямок і відстань малюються програмно. Окремі текстури для конкретних сіл не створюються.

## 10. Стандартні текстури Minecraft

Окремі файли не створюються для пшениці, вовни, сирої баранини, вугілля, необробленої міді, необробленого заліза, каменю, колод, медових стільників, яблук і смарагдів. У GUI використовуються стандартні Minecraft item sprites.

## 11. Загальні технічні правила

- Предмети, блоки та маленькі іконки: 16×16, якщо для конкретного ID не зазначено інше.
- Великі іконки спеціалізацій: 32×32.
- GUI-фони та логотип: 256×256.
- Предмети й іконки мають прозорий фон.
- Заборонені розмиття, згладжування, JPEG-артефакти та напівпрозорий шум по краях.
- Освітлення всіх об'єктів іде з верхнього лівого кута.
- Назви файлів пишуться маленькими англійськими літерами через `_`.
- У фон GUI не вбудовується текст: написи додаються кодом і перекладаються через мовні файли.
- Матеріали з інших модів без дозволу автора зберігаються лише як референси.

## 12. Папка для нових матеріалів

```text
VillageDiplomacy_Textures_v0.1/
├── ready/
│   ├── item/
│   ├── block/
│   ├── gui/
│   │   └── icons/
│   └── branding/
├── references/
│   ├── items/
│   ├── blocks/
│   └── gui/
└── SOURCES.txt
```

- `ready` — власні або дозволені до використання готові PNG.
- `references` — зображення, які задають бажаний стиль, але не переносяться до мода напряму.
- `SOURCES.txt` — автор, посилання та ліцензія стороннього матеріалу.

## 13. Не входить у версію 0.1

- текстури й анімації істот;
- моделі дипломатів і караванів;
- військові прапори;
- шахти, кар'єри, ферми й лісопилки;
- облогові та військові механізми.
